# Express Route Matching Example

This example demonstrates how **Express.js route matching works**, especially how
earlier routes can override later ones if they match first.

---

## Code Example

```js
const express = require("express");

const app = express();

// this following route will always match and rest all routes after it will be ignored
// app.use("/", (req, res) => {
//   res.send("This route will always match and this is printed.");
// });

// Request handler
app.use("/test", (req, res) => {
  res.send("Hello World 55");
});

app.use("/hello", (req, res) => {
  res.send("Hello route");
});

app.use("/hello/2", (req, res) => {
  res.send("Hello 2 route");
});

// If you call http://localhost:3000/hello/2 , you will get "Hello route" as response
// because the above /hello route matches first and the rest are ignored.

app.listen(3000, () => {
  console.log("Server is running on port 3000");
});
```

---

## Key Notes

- `app.use()` matches routes **from top to bottom**
- Once a route matches, **the remaining routes are ignored**
- `/hello` matches `/hello/2`, so `/hello/2` will never be reached unless:
  - You move `/hello/2` **above** `/hello`
  - Or use `app.get()` with exact routing

---

## Correct Order Example

```js
app.use("/hello/2", (req, res) => {
  res.send("Hello 2 route");
});

app.use("/hello", (req, res) => {
  res.send("Hello route");
});
```
